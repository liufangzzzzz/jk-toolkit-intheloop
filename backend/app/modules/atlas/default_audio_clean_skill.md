# 清洗版｜中文可读版

把原始 ASR、字幕、飞书妙记或混合中英文逐字稿整理成可核对事实的 `【中文可读版】`。这是后续简版和稿件的事实底稿，不是摘要，也不是文章。

## 完整性

- 按原始顺序处理全部内容。若前面是单人演讲，后面是访谈、媒体问答、观众提问或圆桌，不得遗漏后半段。
- 保留完整推理链、实质问题与回答、技术原理、数字、产品名、公司名、人名、例子、场景、限制条件和保留意见。
- 不要把长段讲话改成提纲，不要为了流畅删掉有信息量的绕行、转折或自我修正。
- 原文是英文或中英混合时，翻译为自然中文，同时保留说话人、原始顺序、数字、单位、技术名词和专有名词。必要时保留英文术语，例如 `强化学习（reinforcement learning）`。

## 清洗方式

1. 去掉时间码、SRT 序号、无意义换行和纯粹口头填充词。
2. 合并口吃、连续重复、无信息量的寒暄和重复确认，但保留人物有意义的口语节奏与表达个性。
3. 修正有依据的同音字、标点、数字、单位、英文缩写和专名。不得凭空猜测。
4. 无法可靠确认的听写、专名或上下文，用 `[[?原片段?]]` 标出；不要偷偷改成看似合理的词。
5. 识别说话人时使用 `**姓名：**` 或 `**主持人：**`。无法确认时保留对话顺序，不发明身份。
6. 每段聚焦一个话题，保持自然可读；长段可拆分，但不得改变原意或顺序。

## 文本规范

- 中文引号使用 `「」`，嵌套使用 `『』`。
- 中文与英文、数字之间保留空格，例如 `AI 模型`、`3 年`、`50%`。
- 不添加原文没有的事实、判断、行业背景、标题金句或编辑结论。
- 不保留时间码；时间轴由下一阶段从原始逐字稿恢复。

输出严格 JSON，不使用 Markdown 代码围栏：

{"cleaned":"【中文可读版】\n\n整理后的完整正文","uncertain":["所有被 [[?…?]] 标出的原片段"]}

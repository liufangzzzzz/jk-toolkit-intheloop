# In The Loop 内容上传与标签使用指南

这份说明给参与 In The Loop 内容整理、审核和发布的编辑使用。运营入口是工作台中的 **InTheLoop 独立站**。该工具同时管理中文站和英文站；内容先形成草稿，经过人工核对后，再分别发布。

## 一、先理解四个概念

1. **原稿**：粘贴的文章、播客链接，或手动上传、粘贴的文字。
2. **中英文版本**：同一条内容下的两个可编辑版本。它们共用日期、标签和配套资料，但标题、摘要、阅读提示和正文分别保存。
3. **标签**：用于组织知识地图、主题页面、公司资料和内容栏目。
4. **展示方式**：Latest 和 Featured 是内容列表的组织方式，不是标签。

工作台保存的是草稿。点击“发布到中文站”“发布到英文站”或“同步发布中英文站”后，官网才会更新。每次发布会保存当时的发布快照；之后修改草稿不会直接改变已经发布的版本。

## 二、标准上传流程

### 1. 进入上传页面

打开 **InTheLoop 独立站 → 上传内容**。页面会直接进入完整编辑器，不需要先经过额外的“New Story”页面。

### 2. 选择原文语言

- 中文文章、微信公众号、极客公园中文稿、小宇宙中文播客：选择 **中文**。
- 英文原稿：选择 **English**。

原文语言决定系统把首次提取的文字放入哪个版本，也决定默认的翻译方向。

### 3. 导入内容

优先把原文链接粘贴到“原文链接”输入框。系统会尝试识别并提取标题、摘要和正文。

常用来源包括：

- 极客公园官网文章；
- 微信公众号文章；
- 小宇宙节目；
- 其他可公开读取的文章或播客链接。

也可以上传 Word、TXT、Markdown，或直接在正文编辑器中粘贴文字。原始链接在官网统一显示为“原文链接”，本站的发布身份统一为 In The Loop。

小宇宙节目会优先读取带时间轴的中文 transcript。它在本站仍然是一条播客内容，不会因为有 transcript 而重复生成一篇文章。节目详情页顶部可以保留原始收听入口。

### 4. 决定是否调用 AI

导入区有两个独立开关，每个开关都可以选择模型。

中文原稿的默认设置：

- **生成摘要：开启**；
- **生成英文：开启**；
- 两项默认优先使用 GPT-5.6 Terra；
- 两项都可以在处理前关闭。

英文原稿的默认设置：

- **生成摘要：开启**；
- **生成中文：关闭**；
- 如果只发布英文站，保持关闭即可；
- 如果需要同步中文站，再开启“生成中文”。

“生成摘要”实际会同时完成两件事：

1. 生成一段可修改的“阅读提示”；
2. 根据现有资料库推荐内容类型、实体和技术主题。

AI 只给建议。阅读提示、标题、翻译和标签都必须经过人工检查，AI 不会自动创建新标签。

### 5. 核对中英文版本

在“In The Loop 中文站”和“In The Loop 英文站”之间切换，分别检查：

- 标题；
- 原始摘要；
- 阅读提示；
- 正文或 transcript；
- 原文链接；
- 配套内容。

中文转英文使用“英文转换规则”；英文转中文使用独立的“中文转换规则”；阅读提示和标签建议使用“内容分析规则”。三套规则都在 **生成规则** 页面单独维护，互不替代。

“海外观察”只发布中文站。选择后，英文生成会关闭，已有英文发布也会在保存规则允许的情况下撤下。

### 6. 审核标签

确认内容类型、实体和技术主题。AI 推荐的现有标签会加入草稿，但编辑仍然可以删除、补充或调整。

### 7. 填写日期与配套内容

发布日期支持三种精度：

- `2026`；
- `2026-11`；
- `2026-11-03`。

不确定具体日期时不必补齐。Latest 会按照现有日期精度进行倒序排列。

配套内容可加入相关文章、公司官网、播客或其他链接。中文和英文显示名称可以分别填写。

### 8. 保存与发布

- **保存草稿**：只更新工作台，不改变官网上的已发布版本。
- **发布到中文站**：只更新中文官网。
- **发布到英文站**：只更新英文官网。
- **同步发布中英文站**：两个版本都完整时使用。
- **内部内容**：只保存在工作台，不进入官网、搜索或地图。

发布前至少确认标题、正文、阅读提示和标签。英文稿可以单独上传并只发布英文站，不要求必须存在中文版本。

## 三、标签体系

标签分为三类：**内容类型、实体、技术主题**。一条内容可以同时关联多个标签。

### 1. 内容类型

内容类型使用下面的层级：

```text
内容 / Content
├── 深度对话 / Conversations
├── 播客 / Podcast
└── 海外观察 / Global Watch
```

规则如下：

- “内容”是所有内容的顶层标签，系统自动加入。
- 普通文章如果不属于三个子类型，只保留“内容”即可。
- 深度对话、播客、海外观察可以重叠。例如一场人物播客可以同时选择“深度对话”和“播客”。
- 选择“播客”会同步把内容形态设为播客。
- 选择“海外观察”会同步设为仅中文发布。
- 原来的“文章”结构标签已经合并到“内容”，不再单独使用。

**Latest / 最新内容**是按发布日期自动形成的列表。

**Featured / 精选内容**是编辑在“首页精选”中人工选择和排序的列表。

Latest 和 Featured 都属于“内容”的展示方式，但它们不是标签，也不要在 AI 建议中创建为标签。

### 2. 实体

实体包括：

- 公司；
- 产品；
- 人物。

产品可以选择所属公司。人物通过任职关系连接公司，可以记录当前公司、前公司、职位和起止时间。换公司时保留历史任职关系，不覆盖前司记录。

公司和产品可以关联多个技术主题，但这种资料库关系不会自动传给文章。

例如，宇树科技可以关联“人形机器人”和“运动控制”；如果一篇宇树文章只讨论运动控制，该文章仍然必须由编辑直接选择“运动控制”，不能因为公司资料里有关联就自动进入“人形机器人”页面。

### 3. 技术主题

技术主题构成知识地图，可以有任意深度的父子层级，例如：

```text
本体
└── 人形机器人
    └── 更具体的子主题
```

规则如下：

- 每一级技术主题都可以拥有独立页面；
- 每个主题可以选择是否出现在首页旋转地图；
- 地图字号只控制视觉大小，不代表真实层级；
- 主题页可以编辑介绍、人工精选内容和顺序；
- 主题页的“全部相关内容”只收录直接关联该主题的内容；
- 父主题不会自动混入所有子主题文章，兄弟主题之间也不会互相扩展。

## 四、首页与专题页如何取内容

### 中文首页

- **最新内容**：全部已发布中文内容，按日期倒序；
- **精选内容**：在工作台“首页精选”中人工选择和排序；
- **深度对话**：直接带有“深度对话”标签的内容；
- **海外观察**：直接带有“海外观察”标签的中文内容；
- **播客聚合页**：直接带有“播客”标签的内容，按时间倒序。

### 英文首页

英文首页暂时使用 Featured、Latest 和 Conversations。英文界面不展示小宇宙入口，但英文播客稿仍可以作为站内内容发布和阅读。

### 技术主题页

每个技术主题页分开管理：

1. 人工编辑的主题介绍；
2. 人工精选并排序的内容；
3. 根据直接标签关系自动形成的全部相关内容；
4. 关联公司；
5. 子主题。

人工精选不会改变文章标签，文章标签也不会自动进入精选区。

## 五、实习生发布前检查表

- [ ] 原文语言选择正确。
- [ ] 原文链接、标题和正文提取完整。
- [ ] 阅读提示说明“为什么值得读”，没有只复述摘要。
- [ ] 中英文标题、事实、数字、人名和公司名已经核对。
- [ ] 每条内容都显示“内容”标签。
- [ ] 只在确实符合时选择深度对话、播客或海外观察。
- [ ] 公司、产品、人物标签与原文实际讨论对象一致。
- [ ] 技术主题是文章直接讨论的主题，不是从公司资料推断出来的。
- [ ] 日期精度符合现有资料，不编造具体日期。
- [ ] 海外观察没有发布英文版。
- [ ] 发布按钮与目标站点一致。
- [ ] 发布后打开官网链接检查展示结果。

## 六、遇到不确定情况

- 找不到合适标签：先保留 AI 的“建议新增标签”，不要自行创建近义重复标签。
- 不确定是否属于深度对话：看内容是否以人物采访、深入对谈为核心，而不是简单引用几句话。
- 不确定技术标签：只选择正文有实质讨论的主题。
- 英文翻译不确定：保留原文事实和专有名词，先存草稿，请编辑复核后再发布。
- 内容暂时不希望公开：设为“内部内容”，不要发布。

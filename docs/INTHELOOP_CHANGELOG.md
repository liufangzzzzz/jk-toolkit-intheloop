# InTheLoop 当前预览 · 2026-09-22

已同步公司 GitHub 主线，并拆分为工作台仓库与独立官网仓库。正式域名：intheloop.geekpark.net。

## 当前实现
- 新站工作台为“内容 / 标签”两个栏目，保留原运营主题色及旧公众号、极客公园官网上传入口。
- 公司、产品、技术、品类统一为标签；每个标签选择隐藏、小字或大字。上级关系与相关关系分开，关联建议由编辑手动采用。
- 旧资料自动迁移为标签，保留旧表；迁移更新草稿与发布快照的标签关联，重复执行不重复创建。
- 粘贴链接自动识别并抓取文字；已选择可用模型时生成可编辑英文标题、摘要、正文。英文 skill 待配置，当前为基础规则。
- 中文原链接、英文本站正文；配套内容可附相关文章、官网和播客链接。
- 海外观察后端强制只发中文，并阻止旧英文发布记录继续公开。
- 首页中央字标固定，周围标签有纵深的缓慢自转；已修复动画时间差被提前重置导致位移接近零的问题。展开后可拖动，支持暂停及减少动态效果设置。
- 地图下接时间倒序内容；英文 Newsreader 标题与正文，Figtree 界面字；中文思源黑体。左上角使用既有官方 logo 原图。

## 验证与边界
57 个后端测试、10 个前端测试，TypeScript 类型检查和生产构建通过。浏览器核对统一标签编辑、录入首页、双语草稿与持续自转的位置变化。公开官网 HTTPS 抓取连通性已验证；文章抽取和模型结构化输出使用模拟响应测试。

真实模型网关与用户文章尚需 API 配置及实际内容验收。抓取不绕过验证码，动态页面可能需要手动粘贴。当前只处理文字，图片和音频不自动上传或转写。

公开站与工作台分域名、分进程部署，共用数据后端；详细步骤见 INTHELOOP_DEPLOY.md。上线前需同步公司最新仓库并备份 SQLite 卷。

# 飞书公开文档配置（无应用模式）

当前版本不需要创建飞书应用，不需要 App ID 或 App Secret。

## 文档侧操作

1. 打开待发布的飞书新版文档或知识库文档页。
2. 点击右上角「分享」。
3. 开启「互联网用户可阅读」。
4. 复制 `/docx/` 或 `/wiki/` 链接，粘贴到内容发布台。

系统会使用服务器中的无头浏览器读取页面内容并缓存原图。图片缓存默认保留 24 小时。

## 限制

- 目前支持新版 `/docx/` 和知识库 `/wiki/` 文档页。
- 未公开或需要登录的文档会返回权限错误。
- 视频会计数并提示，但不会自动上传到公众号；普通附件、多维表格和嵌入应用不会进入文章。
- 飞书更新网页实现后，公开页面解析也可能需要跟随更新。

## 验收

先粘贴一篇包含标题、作者、Why It Matters、小标题和图片的公开测试文档。确认微信预览正常后，再点击“保存到微信草稿箱”。公众号 Tab 不会直接群发。
